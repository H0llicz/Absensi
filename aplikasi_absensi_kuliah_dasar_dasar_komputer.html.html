Pengaturan Google Sheets API

Masukkan URL Web App Google Apps Script Anda agar data tersimpan otomatis di Google Sheets.

Petunjuk Google Apps Script:

1. Buat Google Sheet baru dengan kolom: Timestamp, Pertemuan, Nama, NIM, Status.
2. Buka Extensions > Apps Script, paste kode backend Google Apps Script yang tersedia di bawah, lalu Deploy sebagai Web App (akses: Anyone).
3. Salin URL Web App dan paste di kolom atas. Jika kosong, data akan disimpan secara lokal di browser.

Kode Google Apps Script (Backend)

Salin kode di bawah ini ke editor Google Apps Script Anda:

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  
  sheet.appendRow([
    new Date(),
    data.pertemuan,
    data.nama,
    data.nim,
    data.status
  ]);
  
  return ContentService.createTextOutput(JSON.stringify({"result": "success"}))
         .setMimeType(ContentService.MimeType.JSON);
}

function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var rows = sheet.getDataRange().getValues();
  var headers = rows.shift();
  
  var result = rows.map(function(row) {
    return {
      timestamp: row[0],
      pertemuan: row[1],
      nama: row[2],
      nim: row[3],
      status: row[4]
    };
  });
  
  return ContentService.createTextOutput(JSON.stringify(result))
         .setMimeType(ContentService.MimeType.JSON);
}
